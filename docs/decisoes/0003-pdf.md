# ADR-0003 — Geração de PDF

- **Status:** aceito
- **Data:** 2026-09-27

## Contexto
O PDF precisa ser consistente, com a marca do freelancer, gerado no servidor (disponível para o dono e para o cliente final) e barato em ambiente serverless.

## Opções consideradas
1. **@react-pdf/renderer**: componentes React próprios, gerado em função Node. Leve e rápido; o template é separado da página web.
2. **Puppeteer + Chromium**: PDF idêntico ao HTML, mas binário de ~50 MB, cold start de 2–5 s, frágil em serverless.
3. **`window.print()`**: sem backend, mas resultado varia por navegador, não é gerado no servidor e a experiência mobile é ruim.

## Decisão
**@react-pdf/renderer** em Route Handler com runtime Node.

## Consequências
- Um template de PDF mantido em paralelo à página pública, em `src/pdf/`.
- Cálculos reutilizam `src/lib/money.ts`, sem duplicar lógica.
- Fontes embutidas (com suporte a acentuação pt-BR) incluídas no bundle.
