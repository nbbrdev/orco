# Segurança

Encontrou uma falha de segurança no Orçô? Obrigado por avisar.

## Como avisar

Escreva para **nbbr.dev@gmail.com**, com:

- o que você encontrou e onde (endereço, tela ou trecho do código);
- os passos para reproduzir;
- o que alguém conseguiria fazer com a falha.

**Não abra uma issue pública** nem divulgue a falha antes de ela ser corrigida: isso expõe quem usa o Orçô.

## O que esperar

O Orçô é mantido por uma pessoa só. Os avisos são lidos e respondidos assim que possível, e as falhas confirmadas são corrigidas na próxima versão.

Não há programa de recompensa.

## Escopo

Vale para o código deste repositório e para o serviço em `orco.nbbrdev.com`. Ataques de negação de serviço, engenharia social e testes que acessem dados de outras pessoas estão fora: não faça.
